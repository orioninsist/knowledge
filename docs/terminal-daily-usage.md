# Secret Break Node — Daily Usage

## Capture

Create or open a Markdown note with the terminal editor.

```bash
nvim note.md
```

## Search

Search by filename:

```bash
fd keyword
```

Search inside notes:

```bash
rg "keyword"
```

## Read

Render Markdown directly:

```bash
glow note.md
```

Quick file view:

```bash
bat note.md
```

## Review

Check changes:

```bash
git status
git diff
```

## Workflow

1. Find
2. Search
3. Read
4. Edit
5. Commit

The workflow keeps Markdown as the permanent knowledge layer while terminal utilities provide speed.
