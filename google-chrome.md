## System Rules

- Tab = aktif çalışma.
- Tab Group = proje veya çalışma bağlamı.
- Bookmark = daha sonra tekrar ulaşılacak kalıcı web kaynağı.
- Knowledge notu = saklanacak ve tekrar kullanılacak bilgi.
- Profile = kimlik ve hesap sınırı; proje değildir.
- Native Chrome çözebiliyorsa extension kullanılmaz.
- Gereksiz Web App kurulmaz.
- Gereksiz sekme açık tutulmaz.
- Gereksiz pinned tab kullanılmaz.
- Performans için Memory Saver aktif tutulur.
- Kaynak sorunu olduğunda Chrome Task Manager ile ölçüm yapılır.

## Standard Project Flow

1. Proje için bir Tab Group aç.
2. Sadece aktif çalışma sekmelerini grupta tut.
3. Tekrar kullanılacak web kaynaklarını Bookmark'a taşı.
4. Değerli bilgiyi ilgili Knowledge notuna aktar.
5. İş bitince gereksiz sekmeleri kapat.
6. Proje tamamlanınca açık çalışma bağlamını temizle.
