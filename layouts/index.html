KN Commands

Terminalden not oluşturma, açma, okuma, taşıma ve silme.

Open / Create
kn code inbox note-name.md Varsa mevcut dosyayı açar · yoksa seçilen MOC'ta oluşturur
Read
kn glow note-name.md Notu terminalde salt okunur görüntüler
Delete
kn rm note-name.md Silmeden önce y/N onayı ister
Move MOC
kn mv note-name.md archives Dosyayı hedef MOC'a taşır · y/N onayı ister
Editors
code zed nvim hx

Global filename selection

Beş MOC dosya seçiminde tek bir global havuzdur. Dosya adı alanı boşken son kullanılan not önerilir. Yazmaya başladığında tüm notlar birlikte filtrelenir ve en fazla 20 sonuç gösterilir.

glow, rm, mv ve editor open/create aynı global filename completion sistemini kullanır.

Mevcut bir dosya hangi MOC'ta bulunursa bulunsun gerçek konumundan açılır. Komutta verilen MOC yalnızca dosya mevcut değilse yeni notun oluşturulacağı yeri belirler.

Knowledge Query

Mevcut notları filtreler ve eşleşen notları tıklanabilir linkler olarak listeler. Yeni not oluşturmaz veya mevcut notları değiştirmez. 

```knowledge
filename: krizim-geldi
```

Filters: filename · content · title · moc · tags · description · status · aliases

Birden fazla filtre aynı blokta kullanılırsa AND olarak uygulanır. 

```knowledge
moc: areas
tags: krizimgeldi
status: active
```
